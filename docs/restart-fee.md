## 1. Context

The rudraspirit.com project was completed and paid in full (₹40,000). Work then
paused for approximately **6 months** with no active development or feedback.

Because the original scope was fully delivered and paid, there is **no
outstanding balance and no kill fee** involved. Resuming work, however, is not a
free continuation — a dormant project has to be brought back to a working,
current, and deployable state before any new work can begin. That reactivation
effort is what the restart fee covers.

---

## 2. Why a restart fee applies

Six months of dormancy creates real, billable work before development can
resume:

| Reactivation task | Why it's needed after 6 months |
|---|---|
| Rebuild local development environment | Site re-imported into LocalWP; DB, config, and URLs re-wired |
| Re-establish deployment pipeline | New SSH keys, deploy scripts, live-server sync set up from scratch |
| WordPress / plugin / theme updates | 6 months of updates for WooCommerce, Elementor, and other plugins |
| Security review & patching | Dormant sites accumulate known vulnerabilities; must be patched |
| PHP / server compatibility check | Host environment and PHP versions move on; code re-verified |
| Data & content reconciliation | Live vs. local database and media brought back in sync |
| Context switching / re-familiarization | Time to reload full project context after moving on to other work |

This is standard practice: freelancers and studios do not resume stalled
projects for free, because resources have been reallocated and pivoting back
costs time.

---

## 3. Restart fee

**Reactivation (restart) fee: ₹6,000** *(one-time, flat)*

Basis: ~15% of the original ₹40,000 project value — the standard 10–20% range
for reactivating paused work. This is a flat reactivation charge, **not** a new
project quote.

> Adjust the figure before sending if you prefer. Reasonable range for this
> project: **₹4,000 – ₹8,000.**

### What the restart fee includes
- Full local environment rebuild (done)
- Live deployment pipeline setup (done)
- Core / plugin / theme updates to current, stable versions
- Security patching and a basic compatibility pass
- Project back on the active schedule

### What it does NOT include
- Any **new** features, redesigns, or scope changes — quoted separately
- Ongoing maintenance / retainer — optional, see §5

1. Restart fee of **₹6,000** payable **in advance**, before development resumes.
2. Any new work beyond the original delivered scope is quoted and approved
   separately.
3. **Response deadline: 5 days** from the date of this document. If there is no

## 5. Going forward — avoiding this next time

To prevent uncompensated stalls in future, the following clause applies to
resumed and new work:

> **Dormancy clause.** If the project receives no client feedback or approval
> for **15 consecutive days**, it is automatically marked *paused*. Resuming a
> paused project requires a restart fee of 10–20% of the project value (or a
> flat reactivation fee), payable before work continues. After **30 days** of
> inactivity the project may be closed and final-invoiced for work completed to
> date.

Optional: a monthly **maintenance retainer** (updates, backups, security,
uptime) keeps the site current and avoids future reactivation fees entirely.
Quote available on request.
